# Persiapan Data

1. Mengimpor dataset ke Excel dan Power Query.
2. Menyesuaikan tipe data setiap kolom.
3. Membersihkan kolom tanggal transaksi agar terbaca sebagai tanggal.
4. Memeriksa error, nilai kosong, dan duplikasi.
5. Memastikan TransactionID memiliki 20.000 nilai unik.
6. Membuat ringkasan jumlah kategori produk per CustomerID.
7. Menghitung tanggal transaksi terakhir dan kelompok waktu transaksi terakhir untuk setiap nasabah.
8. Memuat tabel analisis ke Data Model dan menghubungkan CustomerID nasabah dengan CustomerID transaksi.
9. Membuat measure DAX untuk kebutuhan PivotTable dan dashboard.
