# Sumber Data

Dataset: FP20 Analytics Challenge 27 — Banking Dataset  
Sumber: ZoomCharts, FP20 Analytics June 2025 Challenge  
URL: https://zoomcharts.com/en/microsoft-power-bi-custom-visuals/challenges/fp20-analytics-june-2025

Dataset merupakan data simulasi untuk latihan analisis. Data yang digunakan dalam proyek berisi 20.000 transaksi dari 8.025 nasabah, dengan periode 1 Januari 2023–20 Mei 2025.

Nominal EUR dan USD dianalisis terpisah. Mei 2025 merupakan periode parsial.
